# ivellios-panel

Zbudowany plik panelu Home Assistant (`ivellios-panel-v3.js`, karta `custom:ivellios-panel-v3`).
Kod źródłowy jest w prywatnym repo `home-assistant-bibice` (`panel/v3`); tu trafia tylko wynik `npm run build`,
żeby Home Assistant mógł go pobrać (integracja Downloader → `/config/www/ivellios_v3/`).
